\section{Quick-Fire Definitions (Oral Exam)}
%=============================================================================

\begin{description}
    \item[Service slice] Logical end-to-end network partition with isolated resources and QoS.
    \item[Context-aware slicing] Allocation driven by operational scenario, not static reservations.
    \item[SliceNet] Flow-level classifier mapping traffic to rural service classes.
    \item[RL scheduler] Agent that adjusts priorities/allocations from network state observations.
    \item[HTB] Linux hierarchical token bucket scheduler for bandwidth shaping.
    \item[UPF] User Plane Function; packet forwarding anchor in 5G core.
    \item[MEC] Edge compute hosting low-latency applications near the RAN.
    \item[URLLC] Ultra-reliable low-latency communications slice type.
    \item[Ground truth label] Deterministic label from spawn metadata or measured SLA violation.
    \item[Label leakage] Using oracle label information as ML input, inflating accuracy.
    \item[Closed loop] Sense $\rightarrow$ decide $\rightarrow$ act $\rightarrow$ measure $\rightarrow$ learn cycle.
    \item[Digital twin] Mininet emulation mirroring production network topology and traffic.
    \item[Surplus redistribution] Reallocating unused bandwidth to still-starved slices.
    \item[Markovian state] RL observation containing sufficient information for optimal decisions.
    \item[Zero-synthetic policy] Features must originate from measurable network behaviour.
\end{description}
