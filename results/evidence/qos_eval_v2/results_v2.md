### Evaluation v1 (seeds 0–4) and the defects it exposed

The first contended-regime run used the allocator as first designed. H11–H14 were all **not supported** there; `qos_adaptive` was significantly *worse* than `proposed` on mean class SLA. Two allocator defects explained most of the deficit and were fixed, with regression tests, before the confirmatory run above (fresh seeds 5–9):

* strict-priority degradation starves best-effort TCP (general SLA 0.0 at school@50Mbps and school@1.5x)
* infeasible branch ignores burst headroom, so the loss loop cannot act on overloaded directions (healthcare 0.76 at harvest@50Mbps)
